ПОРТФОЛИО MUNPIE — КАК ЗАМЕНИТЬ ИЗОБРАЖЕНИЯ

Структура:
- index.html — разметка сайта
- style.css — стили и адаптивная вёрстка
- script.js — интерактивность
- images/ — изображения-заглушки, которые можно заменить своими файлами

КАК ДОБАВИТЬ СВОЮ ФОТОГРАФИЮ В HERO
1. Откройте папку images.
2. Замените файл hero-placeholder.png своей фотографией (лучше оставить такое же имя файла).
3. Если хотите использовать другое имя или формат, измените путь в index.html у элемента .hero-visual.

КАК ЗАМЕНИТЬ ПРЕВЬЮ ПРОЕКТОВ
В папке images находятся project-01.png — project-06.png.
Замените каждый файл своим изображением, сохранив имя файла. Либо укажите путь к новому файлу в атрибуте src соответствующего img в index.html.
Рекомендуемый формат: JPG, PNG или WebP. Карточки обрезают изображения по соотношению сторон, чтобы сетка выглядела аккуратно.

КОНТАКТЫ
В index.html найдите секцию id="contacts".
- Ссылка Telegram-канал ведёт на существующий блог.
- Pinterest ведёт на существующий профиль.
- В ссылке «Написать в Telegram» замените your_username на имя личного Telegram-аккаунта.
- В mailto:your@email.com укажите свой адрес электронной почты.

После правок сохраните файлы и откройте index.html в браузере.
